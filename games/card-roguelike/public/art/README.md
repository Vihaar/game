# Card illustrations

`card-atlas.webp` is an original sixteen-cell AI-generated illustration sheet made for The Fold with the built-in image generation tool on 2026-11-24. The PNG source is retained in the session's generated-image directory; this optimized WebP is the game asset. It is not an output of the optional Cloudflare service.

Prompt: a regular 4×4 grid, sixteen square standalone dark-fantasy spell illustrations, no labels or frames, illuminated manuscript and ink-engraving style, indigo/parchment/copper/jade. Subjects by row: ember above book, folded slate shield, dew in silver cup, gust with pages; flare, bastion, spring well, firestorm; obsidian, mist lantern, quill clock, thorn book; lightning rune, torn-paper void, feather and sword, moon-sealed book. Consistent light, tiny-size readable silhouettes, no object crosses a cell boundary.

Starter cards use their corresponding cells. Further procedural discoveries deterministically select a cell. When an operator configures the optional server-side Cloudflare integration, newly forged cards can receive a unique cached illustration and semantic title; combat statistics remain deterministic. Unconfigured or unavailable AI does not interrupt play.
