# Three paper-world previews

These original environment illustrations were generated with the built-in image tool on 2026-11-24 for The Fold's guided-view redesign. They are optimized WebP assets in this directory. No external image API key or paid runtime generation was used. The user requested all three directions for comparison before selecting a final style.

## Shared generation prompt

One wide landscape game environment, approximately 16:9, with the same composition for an art-direction comparison. An enormous magical library built entirely by hand from layered folded paper, cut cardstock, curled strips and bookbinding thread. View from its entrance along a central paper walkway to a monumental open-book doorway at the far end. Two tiers of intricate bookshelves on both sides, elaborate arching cut-paper branches above, suspended pages, folded stairs and tiny paper lanterns. The learner enters knowing nothing, thirsty for all knowledge: convey wonder, invitation and limitless discovery. Rich physical construction, visible fibers, scored folds, thin edges, believable soft contact shadows and miniature-diorama craftsmanship. Low eye-height camera, symmetrical framing with charming asymmetries in book stacks. Clear empty middle foreground third for game characters and an uncluttered central path. No characters, text, UI, card frames, letters or logos. Every effect and object is literal paper, never plastic, metal, painted concept art or generic blocky low-poly geometry. Sharp, detailed art with foreground, middle and back layers.

The style instructions in the table were appended to that shared prompt. PNG originals remain in the session's generated-image directory.
