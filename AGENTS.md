# Working in this repository

Read README.md, CONTRIBUTING.md, docs/GAME_PLANS.md, and relevant game-specific instructions first.

- Search existing open-source engines, examples, templates, and assets before writing new systems. Preserve licenses and attribution in THIRD_PARTY.md.
- Keep reusable behavior in source or scripts, not agent-specific configuration.
- Do not claim a game is playable until its complete interaction works in a browser.
- Run `npm run typecheck` and `npm run build` for code changes. Use meaningful game-rule or regression tests when needed.
- No secrets or backend are needed for initial games. Never commit credentials.
- Keep contributions focused and document validation. Do not merge pull requests without the owner's instruction.
