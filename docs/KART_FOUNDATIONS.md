# Licensed browser kart-racer foundations

Researched 2026-11-24. Goal: remix a complete existing racer into a goofy game starring Torin, Jonah, and Grant. Primary evidence: upstream README, package/config/source files, full license text, repository trees and GitHub REST metadata. Research did not alter the game checkout. Browser playability remains to be tested in the actual local integration.

## Recommended: Turbo Kart Rally

[Source](https://github.com/bridge-mind/turbo-kart-rally) · [Hosted game](https://bridge-mind.github.io/turbo-kart-rally/) · [MIT license](https://github.com/bridge-mind/turbo-kart-rally/blob/main/LICENSE)

The fastest complete 3D foundation identified: buildless JavaScript ES modules, Three.js r170, one existing Palm Cove circuit, eight racers, AI opponents, drift boosts, items, class/lap selection and full race/results progression. Roughly eighteen modular source files make this easier to adapt than a large engine project. [README and module ownership](https://github.com/bridge-mind/turbo-kart-rally#readme).

Actual files to adapt:

- [src/config.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/config.js): title, roster, colors, stats, handling constants and keys. Replace roster with the friends and original rival names.
- [src/models.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/models.js): procedural kart/driver models. Give each friend original headwear/props; avoid retaining recognizable game-character costumes.
- [src/menu.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/menu.js): menus and character selection.
- [src/kart.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/kart.js): existing arcade movement/drifting.
- [src/race.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/race.js): race progression, checkpoints, standings and laps.
- [src/main.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/main.js): renderer, game state and integration.
- [src/track.js](https://github.com/bridge-mind/turbo-kart-rally/blob/main/src/track.js): existing track geometry and collision model.

Asset status: author's README states runtime meshes, textures, sound and music are generated by code; the checked repository tree has no separate runtime image/model/audio asset pack. The MIT file covers upstream software, including those procedural implementations. Preserve its BridgeMind notice and Three.js's MIT notice. [index.html](https://github.com/bridge-mind/turbo-kart-rally/blob/main/index.html) imports Three.js from jsDelivr and Google Fonts; for self-contained integration, use the local Three dependency and system fonts or separately licensed font files. Do not infer that the font files themselves inherit this repo's license.

Upstream roster contains names/costumes visibly close to Nintendo characters (e.g. Toadly/mushroom hat, Koopz/shell). Replace that content with the friends' original designs rather than simply relabeling it. Existing genre mechanics can stay as gameplay foundations.

Deployment: static files, no backend or bundler required by upstream. Keep source under `games/friend-kart/src/` with its license/provenance, and embed/link its own entry page from the game collection. [Exact entry/import map](https://github.com/bridge-mind/turbo-kart-rally/blob/main/index.html). Repository is not archived; pushed 2026-09-22, one commit. This is a small working base, not evidence of long-term maintenance. [GitHub metadata](https://api.github.com/repos/bridge-mind/turbo-kart-rally).

## Examined but not selected

- [Salman4256/kart-rally-race](https://github.com/Salman4256/kart-rally-race): MIT downstream copy of Rally. Its actual tree adds touch controls, more tracks, ghost/grand-prix/customization/PWA modules; README still links upstream for the demo. Potential source for licensed incremental features, but upstream is smaller for the first remix. Verify advertised additions locally before copying them.
- [ai-zundamon/voltcrest](https://github.com/ai-zundamon/voltcrest): attractive complete procedural racer, but its [LICENSE/README explicitly reserves rights](https://github.com/ai-zundamon/voltcrest#licence) and forbids copying, modification, hosting or redistribution without written permission. **Do not reuse this game's code or assets.** Its vendored Three.js license does not license the game.
- [yashwanthNDev/beach-karts](https://github.com/yashwanthNDev/beach-karts): README says MIT but no license file was found in the inspected root/GitHub metadata. Also arena combat, not a lap racer. Rally offers clearer licensing and a closer loop.
- [ryancampbell/kart-royale](https://github.com/ryancampbell/kart-royale): MIT, procedural assets, live demo and extensive instrumentation, but its own README reports about 60,500 lines. Too large for the fastest small remix.

## Integration plan

1. Vendor the existing Rally game and its MIT notice under a dedicated game directory; record upstream repo and pinned commit.
2. Reuse its full race/track/AI/drift/item loop. Replace roster, procedural character styling and copy with Torin, Jonah, Grant and original jokes.
3. Make the first round short with one lap; preserve existing class selection and easy difficulty.
4. Run real browser checks for menu, acceleration/steering, drifting, lap completion, results and restart. A static source fetch or screenshot alone does not establish that the race is fun or correct.
